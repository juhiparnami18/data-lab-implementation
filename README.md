## 📊 Dataset (synthetic)

Three related tables generated by `generate_data.py` (fixed seed = 42):

| Table | Rows | Contents |
|---|---|---|
| `customers.csv` | 400 | customer_id, city, age, gender |
| `products.csv` | 20 | product, category, unit price, cost price |
| `orders.csv` | 3,015 | order_id, customer, product, date, quantity, discount, payment method |

The data is **deliberately messy**: 15 duplicate orders, 24 missing ages, mixed-case city names and dates stored as text.

> ℹ️ The data is synthetic, so insights describe the simulation and not a real business.

## 📐 Statistical choices (explained in the notebook, section 5.4)

| Question | Method | Why |
|---|---|---|
| Do discount and quantity move together? | Pearson **and** Spearman | Pearson is linear but outlier-sensitive; Spearman is rank-based and robust to skew |
| Do high-discount orders hold more items? | Welch t-test + Cohen's d + Mann-Whitney | Unequal variances, effect size, and a non-parametric robustness check |
| How precise is the average order value? | Bootstrap 95% CI | Order value is right-skewed, so a normal-theory interval is less reliable |
| Summarising skewed values | Median + IQR beside the mean | Large orders pull the mean up |

> Discount vs revenue is *statistically significant* (r = 0.06) but explains only ~0.4% of the variation, so it is **not practically important**. Significance is not the same as importance.

## ⚠️ Limitations and biases of the synthetic data (notebook section 5.5)

- **Circularity:** the generator itself contains a festive-season boost and a discount-to-quantity link, so the analysis *recovers* these patterns rather than *discovering* them.
- **Simplified randomness:** customers and products are chosen uniformly; real shoppers have habits.
- **Arbitrary proportions:** city, payment and discount shares were chosen by the author.
- **One year, fixed prices, no returns or cancellations:** revenue is overstated compared with a real business.
- **Random mess:** real missing data is rarely random, so median filling is riskier in practice.
- **Small, clean sample:** tests become significant easily; real effects are noisier.
